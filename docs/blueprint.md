# **App Name**: SDG Champions Hub

## Core Features:

- Homepage Showcase: Display a dynamic homepage with a hero section, mission statement, and key statistics using glassmorphism design.
- SDG Goals Directory: Implement a comprehensive listing of the 17 UN SDGs with detailed information, project examples, and engagement opportunities.
- Chapter Spotlights: Create interactive chapter pages with member highlights and events, enhanced with animated hover effects for engagement.
- Officer Dashboard: Enable officers to log in, submit volunteer hours, access resources, view chapter stats, and message regional leads.
- Chapter application form: Allow new chapters to submit their application online
- Team Showcase: Feature a team page with modular cards and soft hover effects, showcasing team members and their contributions.
- AI Project Summaries: Incorporate an AI tool for automatically generating summaries of SDG projects.

## Style Guidelines:

- Primary color: SDG Green (#3AC47D) for a fresh, empowering feel.
- Background color: Light gray-white (#f7fafc) for a clean, minimalist aesthetic.
- Accent color: Subtle contrast color (#EDF2F7) to enhance readability without overpowering.
- Headings: 'Space Grotesk' (sans-serif) in bold (42-56px range) for a modern, impactful look. Note: currently only Google Fonts are supported.
- Body Text: 'Inter' (sans-serif) in 16-18px for clear, accessible information. Note: currently only Google Fonts are supported.
- Use SDG-related icons in the official SDG colors to reinforce each goal's identity.
- Employ rounded corners (border-radius: 24px) and soft drop shadows (box-shadow: 0 8px 24px rgba(0,0,0,0.08)) for a gentle, modern feel.
- Apply subtle fade-in animations using Framer Motion or ScrollTrigger for on-scroll section reveals, enhancing user experience.
